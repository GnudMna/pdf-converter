# 使い方

## 基本の流れ

1. **ファイルを開く:** 次のいずれかで PDF / Word を読み込む
   - **参照** ボタンからファイルを選ぶ
   - ファイルの欄にパスを入力し、`Enter` を押すかフォーカスを外す
   - ウィンドウへドラッグ&ドロップする (読み込めるのは 1 ファイルのみ。複数ドロップすると先頭の対応ファイルだけを読み込み、その旨を通知する)
   - コマンドライン引数で指定して起動する ([コマンドライン](cli.md) を参照)
   - パスワードで保護された PDF は、読み込み時にパスワードの入力ダイアログが表示される。パスワードを入力して **開く** を押す (誤ったパスワードの場合は、もう一度入力を求める)
2. **プレビューを確認する:** ページを移動しながら出力内容を確認する
3. **変換設定を選ぶ:** 出力形式・出力解像度・透明度を指定する
4. **保存するページを選ぶ:** **全ページを保存** にチェックを入れるか、ページ番号または範囲を入力する
5. **画像として保存** を押し、出力先フォルダーを選ぶ (前回選んだフォルダーから始まる)

左右のパネルの間にある境界をドラッグすると、パネルの幅を変えられる。

## プレビュー

- 前後のページへは、プレビュー下のボタンか `Ctrl+←` / `Ctrl+→` で移動する
- ページ番号の欄に番号を入力して `Enter` を押すと、そのページへ移動する
- プレビューは表示枠の大きさに合わせて描画する。ウィンドウを広げると、少し待ってから広げた大きさで描画し直す
- **プレビューをコピー** で、表示中のページを出力解像度の画像としてクリップボードにコピーする

## 変換設定

| 項目 | 内容 |
| :--- | :--- |
| 出力形式 | PNG / JPEG / BMP |
| 出力解像度 | **幅 (px)**・**高さ (px)**・**DPI** のいずれかを選び、数値を入力する。幅・高さを指定しても縦横比は保たれる |
| JPEG 品質 | 1〜100 の数値 (既定は 90)。大きいほど高画質でファイルサイズも大きくなる。出力形式が JPEG のときのみ有効 |
| 保存ページ | **全ページを保存**、またはページ番号・範囲 (例: `1,3-5`。`5-` で 5 ページ目から最終ページまで) |
| 透明度 | **透明度を保持** をオンにすると、PNG で背景の透明度を残す。オフの場合と JPEG は白背景で合成する |

設定は次回の起動時にも引き継がれる。

## 保存されるファイル

出力先フォルダーに `page_1.png`、`page_2.png`、… の名前で保存する。
ページ番号は、名前順に並べてもページ順になるよう、総ページ数の桁数までゼロ埋めする (例: 12 ページの PDF なら `page_01.png` ～ `page_12.png`)。

同じ名前のファイルがある場合は、上書きするかを確認する。

保存中は **キャンセル** で中断できる。

変換や保存の処理中にウィンドウを閉じようとすると、確認のダイアログを表示する。**中止して終了** を選ぶと、処理を中止して Word や LibreOffice の後片付けを待ってからアプリを終了する。

## Word 文書

Word 文書 (`.doc` / `.docx`) は、いったん PDF に変換してから表示・画像化する。
変換には Microsoft Word または LibreOffice を使う。

**Word 設定** を開くと、次を選べる。

| 項目 | 内容 |
| :--- | :--- |
| Word → PDF 変換 | 変換に使うソフト (**Microsoft Word** / **LibreOffice**) |
| LibreOffice 実行ファイル | `soffice.exe` のパス。空欄の場合は一般的なインストール先から自動で探す。入力後 `Enter` を押すかフォーカスを外すと反映する |
| PDF 形式 | **標準 PDF** / **PDF/A-1** (長期保存向け) |
| 出力最適化 | **印刷向け** / **オンライン向け** (ファイルサイズを抑える) |
| しおり (見出し) を出力 | 見出しスタイルから PDF のしおりを作る |
| コメントを含める | 文書のコメントを PDF に出力する |

Word 文書の読み込み・変換中は **Word 設定** を変更できない。変換が終わってから設定を変えると、新しい設定で変換し直す。

Word 文書を開いているときは **PDF として保存** が表示され、変換した PDF をそのまま保存できる。

## テーマ

右上のテーマ切り替えで **ライト** / **ダーク** / **システム** (Windows の設定に合わせる) を選ぶ。

## バージョン情報と更新

右上の **ⓘ** ボタンでバージョン情報を開く。

- **更新を確認:** 公開中の最新版を確認する。新しい版がある場合は、インストーラーをダウンロードし、アプリを終了して更新する。更新中は進捗を表示し、完了するとアプリが自動で起動する
  - ポータブル版は、インストーラーの代わりにポータブル版の zip をダウンロードし、アプリのフォルダーのファイルを置き換える。設定 (`UserData\`) は引き継ぐ。同じフォルダーの PDF Converter (`pdfconv.exe` を含む) が動いている間は置き換えられないため、終了を求める ([インストール版とポータブル版](introduction.md#インストール版とポータブル版))
- **使用許諾を開く:** 本アプリの使用許諾 (`LICENSE.txt`) を開く
- **OSS ライセンスを開く:** 同梱しているオープンソース ソフトウェアのライセンス全文 (`THIRD-PARTY-NOTICES.txt`) を開く
- **設定をリセット:** 保存済みの設定をすべて既定値に戻す
