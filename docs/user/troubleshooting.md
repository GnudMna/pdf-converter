# トラブルシューティング

## ログ

問題が起きたときは、次のログを確認する (UTF-8 のテキスト)。2 MB を超えると新しいファイルに切り替わり、古いログは `app.log.1` ～ `app.log.5` のように 5 世代まで残る。

| ファイル | 内容 |
| :--- | :--- |
| `%LOCALAPPDATA%\PDF Converter\logs\app.log` | 操作の記録・警告 |
| `%LOCALAPPDATA%\PDF Converter\logs\error.log` | エラーの詳細 |

ポータブル版は、展開したフォルダーの `UserData\logs\` に `app.log` と `error.log` を書く。

## よくあるエラー

| 症状 | 原因と対処 |
| :--- | :--- |
| 「描画サイズが上限を超えています」と表示される | 1 ページあたりの描画画素数は、x64 版で 3 億画素、x86 版で 1 億画素まで。解像度 (幅・高さ・DPI) を下げる |
| パスワード付き PDF を開こうとするとパスワードの入力を求められる | PDF を開くためのパスワード (ユーザーパスワード) を入力する。誤ると、もう一度入力を求める。キャンセルすると読み込みを中止する |
| コマンドラインで「パスワードで保護された PDF です」と表示される | `--password` でパスワードを指定する。コマンドラインを他のプログラムから見られたくない場合は `--password-file` などを使う ([コマンドライン](cli.md#パスワードの渡し方) を参照) |
| 破損した PDF を開けない | PDF を修復してから読み込む |
| Word 文書の変換が失敗する・終わらない | Microsoft Word または LibreOffice がインストールされているか確認する。変換は 5 分でタイムアウトする。LibreOffice は専用の設定で起動するため、起動中の LibreOffice には影響しない |
| LibreOffice が見つからない | **Word 設定** の **LibreOffice 実行ファイル** に `soffice.exe` のパスを指定する |
| **更新を確認** から更新したあと、アプリが起動しない・版が変わらない | 更新のログ `%TEMP%\PdfConverter\updates\<版>\setup.log` でエラーを確認する。同じフォルダーにあるインストーラー (`PdfConverter-<版>-<x64 / x86>-setup.exe`) を直接実行すると、ウィザードで更新できる |
| ポータブル版で **更新を確認** から更新したあと、版が変わらない・エラーが表示される | 展開したフォルダーの `UserData\logs\error.log` を確認する。置き換えに失敗した場合は元のファイルに戻している。新しい版の zip をダウンロードし、`UserData\` 以外のファイルを上書きしても更新できる |
| 0.6.0 以前の版からの更新で「以前のバージョンの PDF Converter をアンインストールできませんでした」などと表示され、インストールが中止される | Windows の **設定 → アプリ → インストールされているアプリ** から旧版の **PDF Converter** をアンインストールしてから、もう一度インストールする |

## 一時ファイル

変換途中の一時ファイルは `%TEMP%\PdfConverter` 配下に作り、アプリの終了時に削除する。

画像を保存している間は、保存先フォルダー内に `.pdfconverter-staging-` で始まる隠しフォルダーを作り、完了・失敗・キャンセルのいずれでも削除する。
保存中にアプリを強制終了するなどしてこのフォルダーが残った場合は、24 時間後以降に同じ保存先へ保存したときに自動で削除する。すぐに消したい場合は、手動で削除してもよい。

## 設定の初期化

設定 (テーマ・変換設定・Word 設定など) は Windows のユーザーごとの設定ファイル (`user.config`) に保存する。
ポータブル版は、展開したフォルダーの `UserData\user.config` に保存する。
起動時に設定ファイルの破損を見つけた場合は既定値に戻し、バージョンアップ時は前の版の設定を引き継ぐ。

手動で初期化する場合は、バージョン情報 (右上の **ⓘ** ボタン) の **設定をリセット** を使う。

## アンインストール

Windows の **設定 → アプリ → インストールされているアプリ** から **PDF Converter** をアンインストールする。

アンインストールしても、次は残る。不要な場合は手動で削除する。

- ログ: `%LOCALAPPDATA%\PDF Converter\logs\`
- 設定: `%LOCALAPPDATA%\PdfConverter\` 配下の `user.config`
- 0.6.2 以前の設定: `%LOCALAPPDATA%\Yuto_Hirata\`。新しい版を一度でも起動していれば引き継いで削除済みのため、残っているのは一度も起動していない場合だけ

ポータブル版はアンインストールせず、展開したフォルダーごと削除する。設定とログはフォルダー内 (`UserData\`) にあるため、ほかに消すものはない (一時ファイルは `%TEMP%\PdfConverter` に作り、終了時に削除する)。
