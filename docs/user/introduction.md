# PDF Converter

PDF または Word 文書の各ページを **PNG / JPEG / BMP** の画像として書き出す Windows アプリ。
変換前にプレビューを確認しながら、解像度や出力するページを指定できる。

## できること

- 各ページのプレビュー表示 (前後移動・ページ番号を指定して移動)
- 単一ページ・ページ範囲 (例: `1-3,5`)・全ページの保存
- 幅 (px)・高さ (px)・DPI による出力サイズの指定
- JPEG 出力時の品質 (1〜100) の指定
- PNG 出力時の透明度の保持
- プレビュー画像のクリップボードへのコピー
- Word 文書 (`.doc` / `.docx`) の画像化と、PDF としての保存 (Microsoft Word または LibreOffice を使用)
- ドラッグ&ドロップ・コマンドライン引数でのファイル指定
- ウィンドウを表示しないバッチ変換 (コマンドライン。スクリプト向けのコンソール用起動プログラム `pdfconv.exe` を同梱)
- ライト / ダーク / システム設定に合わせたテーマ
- 更新の確認と適用

## 動作環境

- Windows 10 / 11 (x64 版・x86 版)
- .NET ランタイムのインストールは不要 (アプリに同梱)
- Word 文書を変換する場合は、**Microsoft Word** (デスクトップ版) または **LibreOffice** のいずれかが必要

## インストール版とポータブル版

配布物は 2 種類ある。機能は同じで、置き場所・設定の保存先・更新の方法が異なる。

| 項目 | インストール版 (`PdfConverter-<版>-<x64 / x86>-setup.exe`) | ポータブル版 (`PdfConverter-<版>-<x64 / x86>-portable.zip`) |
| :--- | :--- | :--- |
| 導入 | インストーラーを実行する。`%LOCALAPPDATA%\Programs\PDF Converter` に入る | zip を任意のフォルダーに展開し、`PDF Converter.exe` を実行する |
| 設定・ログ | `%LOCALAPPDATA%` に保存する | 展開したフォルダーの `UserData\` に保存する (PC には残さない) |
| スタートメニュー・ファイルの関連付け | 登録できる | 登録しない |
| 更新 | **更新を確認** からインストーラーで更新する | **更新を確認** から、展開したフォルダーのファイルを新しい版に置き換える。`UserData\` は引き継ぐ |
| 削除 | Windows の設定からアンインストールする | フォルダーごと削除する |

ポータブル版は、展開したフォルダーにある `portable.txt` で判定する。このファイルを削除すると、インストール版と同じ場所に設定を保存し、更新もインストーラーで行うようになるため、削除しない。
ポータブル版は書き込みできるフォルダー (USB メモリ・ドキュメントなど) に置く。`C:\Program Files` のような書き込みできない場所では、設定を保存できず、更新もできない。
